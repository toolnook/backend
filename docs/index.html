Stellar Horizon Gateway

A rate-limiting, caching, and circuit-breaking gateway for the Stellar Horizon API. Helps applications access Stellar network data reliably without hitting rate limits or cascading failures.

Why it helps Stellar

Horizon Caching

Caches idempotent GET responses (accounts, ledgers, transactions) to reduce load on Horizon

Rate Limiting

Token-bucket algorithm keeps your app under Horizon's rate limits

Circuit Breaker

Trips on repeated Horizon 5xx errors to prevent cascading failures

Network Validation

Validates public vs testnet passphrases to prevent cross-network mistakes

Prometheus Metrics

Monitor Horizon API usage with request counts and response times

Soroban Support

Route to Soroban RPC with separate circuit breaker configuration

Quick Start

git clone https://github.com/toolnook/backend.git
cd backend
npm install
cp config.example.yaml config.yaml
npm start

Configuration

port: 8080
stellar:
  network: public
  horizonUrl: https://horizon.stellar.org

routes:
  - id: horizon
    path: /
    upstreams:
      - name: stellar-horizon
        url: https://horizon.stellar.org
    rateLimit:
      capacity: 100
      refillRate: 50
    circuitBreaker:
      threshold: 5
      resetTimeout: 30000

Horizon Client API

import { HorizonClient } from './src/stellar/horizon';

const client = new HorizonClient({
  baseUrl: 'https://horizon.stellar.org',
  network: 'public',
  cacheTtl: 10000,
});

const account = await client.getAccount('GABC...');
const ledger = await client.getLatestLedger();
const { payments } = await client.getPayments('GABC...');
